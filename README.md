# [Jack-Thorp.com](https://jack-thorp.com)
### [Cloud Resume Challenge](https://cloudresumechallenge.dev/)

### Summary
To continue growing and developing my skills, one of my mentors introduced me to this [Cloud Resume Challenge](https://cloudresumechallenge.dev/). 

The challenge was all about getting my hands dirty with different parts of software development:
- **Building a Webpage**: Using *HTML*, *CSS*, and *JavaScript*
- **Deploying the Site**: via *S3* and setting up *HTTPS*
- **Custom DNS and CloudFront**: Pointing a custom domain to the site and deploying through *CloudFront*
- **API Development**: Creating an API using *Lambda*, *API Gateway*, and *DynamoDB* to track visitors, including enabling *CORS*
- **Source Control** Learning about Git and setting up a *GitHub* repo

Overall, I am happy with how this project turned out. It has been an incredible learning experience, plus holds potential for future improvements and updates!
