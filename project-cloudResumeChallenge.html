Creating Jack-Thorp.com

So I guess the appropriate first project I broadcast on this site… is the site itself!
Jack-Thorp.com did not start just to host my resume; it began as a learning adventure to grow my cloud computing knowledge.
During my time at Advoco/Accenture, I found myself always wanting to learn more regarding how things worked. And what better way to learn than diving right into projects! My journey began with mostly database tasks, expanded to integrations and front end enhancements, and eventually led to full-scale projects in AWS and Azure.
Since I never had formal training in software development or computer science, I have been super blessed to have several mentors who helped me advance my knowledge. One of those mentors, Todd Porter, introduced me to the Cloud Resume Challenge - which is a hands-on learning exercise to create and host a full-stack website via AWS.
The challenge was all about getting my hands dirty with different parts of software development:
  • Building a webpage with HTML, CSS, and JavaScript
  • Deploying a site via S3 and setting up HTTPS
  • Pointing a custom DNS domain to the site and deploying through CloudFront
  • Creating a visitor counter using Lambda, API Gateway, and DynamoDB
  • Setting up a source control repository on GitHub
Overall, I am happy with how this project turned out. It has been an incredible learning experience, plus holds potential for future improvements and updates. Thanks for checking out my site, and I can not wait to share what is next!
